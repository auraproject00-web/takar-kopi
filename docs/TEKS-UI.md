# Teks UI · Indonesia & English

Daftar semua teks di aplikasi. Kolom **Kunci** nanti dipakai langsung sebagai key di file terjemahan (`id.json` dan `en.json`).

Aturan gaya:
- **Indonesia**: santai tapi sopan, tanpa "lu/gue". Pakai "kamu" kalau perlu menyapa.
- **English**: singkat dan ramah, istilah kopi pakai yang umum dipakai barista (bloom, pour, grind size).
- Nama metode dan merk (V60, AeroPress, Comandante, dll.) **tidak diterjemahkan**.
- Angka pakai titik desimal di dua bahasa (mis. `1:16.5`) supaya konsisten dengan timbangan.
